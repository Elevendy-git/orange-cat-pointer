# 橘猫鼠标跟随

一只坐着的长毛橘猫，头部和视线会跟随鼠标方向转动。支持白色、深灰背景、触屏拖动和系统的减少动态效果设置。

[在线体验](https://elevendy-git.github.io/orange-cat-pointer/)

## 本地运行

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/>。项目使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 操作

- 桌面端：移动鼠标，橘猫会朝相应方向转头；鼠标离开页面后恢复初始姿态。
- 触屏端：在画面内按住拖动，松开后恢复初始姿态。
- 点击“白色”或“深灰”切换背景。
- 开启系统的减少动态效果后，显示静态橘猫。

## 文件

- `index.html`：演示入口。
- `pilot/`：页面样式与鼠标、触屏交互代码。
- `final/`：透明静态图、109 帧 WebP 图集和方向映射。
- `build/timeline.json`：动画时间轴。

角色使用 160 × 160 CSS 像素显示。所有动画资源均为本地文件，浏览器运行时无需账户、API Key 或模型调用。
